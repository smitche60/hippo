# Watched sources

Folders the dream sweeps every run (paths relative to the folder this repo lives in). New or
changed text files (.md, .csv, .txt) are distilled — never copied. Binaries, zips, and
screenshots are skipped. Add a line to watch a folder; remove it to stop. State:
`.dream-state.json` (gitignored).

- ../example-working-folder/

Replace the example with the working folders whose churn you want distilled into the brain.
